# Pakistan Road Accident Analysis (50K Rows)

EDA and predictive modeling on a 50,000-row Pakistan road accident dataset.

## What it does
Analyzes accident patterns, builds a severity prediction model, and uses SHAP for explainability.

## Tech Stack
- Python, Jupyter Notebook
- - Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, SHAP
 
  - ## How to Run
  - 1. Clone the repo
    2. 2. Open `analysis.ipynb` in Jupyter
       3. 3. Run all cells
         
          4. ## Key Features
          5. - 50K row dataset EDA
             - - Accident severity classification
               - - SHAP feature importance
                 - - Pre-trained model: `accident_severity_model.pkl`
